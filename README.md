# Radio Live FM AM

Android 網路收音機與 Podcast App，使用 Kotlin、Jetpack Compose 與 Material 3。

## 功能

- 在地與世界電台、Podcast、分類瀏覽與我的最愛
- 背景播放，支援通知列與鎖屏控制
- 睡眠計時與鬧鐘
- 音效與等化器
- 多語言介面

電台資料來自 Radio-Browser 社群目錄。

隱私權政策：https://apsmkimo.github.io/privacy-go2radio.html

## 建置

需要 JDK 17+ 與 Android SDK。

```bash
./gradlew assembleDebug
```
